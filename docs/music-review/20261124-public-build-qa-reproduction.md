## Build preflight

Some developer worktrees intentionally exclude *.ogg and other large media via sparse checkout. Vite can return the SPA HTML for missing audio with HTTP 200; a successful status is not audio decode evidence. Never diagnose the resulting EncodingError as a production regression without checking the exact asset inventory.

Build the selected source using the normal npm build, from a complete checkout. In a sparse worktree, the following safely restores the tracked public packs into the already built, ignored dist tree (not the source tree, and not private media). Use the actual build commit as REF:

```sh
REF=$(git rev-parse HEAD)
npm run build
git archive "$REF" public/music/packs | tar -x -C dist --strip-components=1
python3 tools/music/verify-public-build-media.py dist --ref "$REF"
```

The verifier compares the complete OGG path set, byte lengths, OggS header, and Git blob hashes. It rejects missing, extra, symlinked or modified OGGs. The public build still needs its catalog and manifest JSON, generated by the normal build. The preflight is not an audio decoder or subjective sound test.

