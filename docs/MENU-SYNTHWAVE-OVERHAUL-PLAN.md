# Plan: Synthwave Arcade-Cabinet overhaul of all menu screens

## Context
User wants the main menu screens "zhuzhed up 10x". Interview answers:
- **Scope:** Title + its modal sub-views (Profile, Shop, Leaderboard, Settings, Seed, Daily modes, etc.) + Pause + Game Over.
- **Direction:** Synthwave arcade cabinet — push the existing neon-Tron identity hard.
- **Motion:** Lots, but respect a reduce-motion setting / OS `prefers-reduced-motion`.
- **Layout:** Reorganize freely; every feature must stay reachable by keyboard, gamepad, mouse and touch.

**Art policy (updated by user):** the old "procedural only" rule is lifted — authored art is allowed when it's the right tool. Use **hand-authored SVG** (generated by the agents) for rich static layers: logo wordmark, retro sun, mountain silhouettes, panel frame/ornament 9-slices, rider sprite, icons. Files live in `public/assets/menu/`, loaded in `src/scenes/PreloadScene.js` via `this.load.svg(key, url, { width, height })` at exact native pixel sizes (480×270 world, so art is authored for that grid and stays crisp with `pixelArt: true`). **Palette rule:** art that carries accent colour is authored white/greyscale and tinted at runtime from `Theme` (`setTint(pal.x)` inside `theme.bind`) so the colour-blind palette and equipped UI themes still apply; only neutral/luminance art bakes its colours. Keep procedural `Graphics` where animation needs it (grid, stars, glow pulses, transitions). A missing asset must never block the menu (fallback to the current procedural draw).

Constraints found in the code: Phaser 3, 480×270 `pixelArt: true`, custom bitmap `PixelFont` + `NeonText`, palette via `Theme` (colour-blind palette + equipped UI theme must keep working; `danger` never recolored). Title geometry is unit-tested (`src/ui/MissionsLayout.js` `TITLE_BANDS`/`titleMenuLayout`, `ProfileLayout.titleBadgeLayout`, tests in `tests/src/missionslayout.test.js`, `views-navigation.test.js`, `w4-screen-gates.test.js`, etc.). Repo has no `node_modules` yet → `npm install` first.

## Design language
- **Sky:** deep gradient (bg → magenta-tinted horizon) with twinkling starfield, occasional shooting star.
- **Retro sun:** big striped sun (horizontal slice gaps that scroll) sitting on the horizon, magenta→amber.
- **Parallax ranges:** 2–3 silhouette mountain layers with neon rim lines, scrolling at different speeds; the existing perspective grid floor kept but brighter, with a speed-up "warp" on START RUN.
- **Attract-mode rider:** small sled rider (the player's triangle-ish primitive) carving across the far hills, occasional airborne trick.
- **Logo:** authored SVG wordmark BITSTREAM / BLUFFS in chrome/gradient synthwave lettering (luminance layer + tinted outline layers for magenta/cyan chromatic split), periodic glitch slice + RGB split, gentle wave kept.
- **CRT:** existing scanlines + vignette, plus a slight rolling bright band and a power-on intro (line expands to full screen) on first boot only.
- **Panels:** glass-dark fill, double neon border with soft glow (multiple stroke passes at falling alpha), animated corner brackets, title bars as angled "tabs".
- **Menu:** big 2× labels, animated selection bar (gradient sweep + chevron cursor that slides between rows with easing), selected item gets glow pulse; hover sfx tick; confirm flash.
- **Transitions:** views scale/slide in from the cabinet centre with a CRT "zip"; dim layer fades; scene changes use a wipe/scanline transition.
- **Reduce motion:** new setting `reduceMotion` ('auto'|'on'|'off', auto = OS `matchMedia('(prefers-reduced-motion: reduce)')`) in SettingsView; when active: no glitch/shake/warp, starfield & parallax slowed or static, transitions become short fades.

## Title reorganisation

- Menu becomes left/centre column of 6 items on a translucent panel (same items/order; DAILY RUN keeps its rule sub-label).
- CONTROLS panel moves into a new **HOW TO PLAY** view (reachable from Settings and via a hotkey `H`/pad Select hint) — frees the right side for a **"cabinet card" column**: level badge/title, BEST, daily patch card (rule, countdown, streak), missions list.
- Jukebox HUD stays, restyled to fit the new right column.
- "PRESS START" blink + attract feel when idle >20 s (menu fades slightly, rider does a trick), any input restores.
- Update `MissionsLayout.TITLE_BANDS`/related layout helpers + their tests so geometry remains tested and non-overlapping (tests are updated deliberately, never skipped).
