# #244: observed replay-evidence storage corpus (2026-11-25)

This is **measured evidence**, not an estimate based on a synthetic toy replay. Reproduce with `node tools/replay/measure-evidence-corpus.mjs --json` and `GAME_URL=http://127.0.0.1:PORT/ node tools/replay/test-real-evidence-corpus-browser.mjs` against a Vite server from the same checkout. Use a clean browser origin. **The harness performs no score submissions and checks for mutating network requests.**

The measured source consists of **46 existing, checked-in recorded `.tape.json` files**, from `tools/conformance/fixtures/cross-engine{-sim6}` and `tools/determinism/{portable-math/,}fixtures`, which were independently replay/test fixtures before this work. Each tape is converted into a full canonical `bb-replay-evidence` legacy-derived envelope using `legacyManifestFromTape()` and `evidenceBundle()` and validated with `validateEvidenceBundle()`; **46/46 pass**. All 46 envelope digests are distinct.

| Observed size (bytes) | Min | Median (lower middle) | P95 | Max | Total |
| --- | ---: | ---: | ---: | ---: | ---: |
| Source recorded tape JSON | 5,703 | 19,451 | 83,912 | 86,627 | 1,174,100 |
| **Complete canonical evidence envelopes** | **2,867** | **11,101** | **38,274** | **41,223** | **641,120** |
| Gzip level 6 envelopes, diagnostic only | 1,451 | 3,373 | 8,379 | 9,075 | 176,730 |

Real headless Chromium IndexedDB acceptance, using the served v3 module with each browser envelope checked against the Node-side canonical digest, stored all 46 complete canonical envelopes as **unbound archive-only imports**, reopened and verified the original bytes of all 46, explicitly removed five, reopened and verified the five were absent and the other 41 remained; **PASS with zero page errors**. It also refused a run-bound protected reference for an unbound historical import with exact `run-id-mismatch`. No mutating browser HTTP requests were observed. `navigator.storage.estimate()` at the local test origin reported initial usage 147,456 bytes, usage after the 46 saves 573,440 bytes (delta **425,984 bytes**, about **416 KiB**); this browser estimate counts origin-wide storage, may be rounded or delayed and **is not a byte-accounting substitute** for the 641,120 bytes of canonical envelope payload. The browser reported roughly 10 GiB quota; this does not establish that such quota is available on Chromebooks or under mobile storage pressure.

**Limits:** These are historical recorded tapes converted into legacy envelopes. They are **not new production SIM9 live-capture replay evidence**, nor proof of historical scores, genuine entitlements, or original capture provenance. The v3 IndexedDB payloads are uncompressed; gzip figures are diagnostic, not promised storage savings. The totals exclude database indexes, run references, tombstone metadata and any non-archive assets. This test exercises a real storage write/reopen/delete lifecycle at observed corpus size, **not forced quota exhaustion**. Current production full-envelope corpus, multi-run identical-byte binding policy and realistic Chromebook storage-pressure/error handling remain release acceptance items for #244. No public verifier or upload is enabled.

**Source-integrity caveat:** Node computes each raw recorded tape SHA-256 plus its canonical envelope digest and length. Chromium fetches each exact fixture URL without redirects, verifies the **raw-response SHA-256** first, then rebuilds the envelope and checks its digest and length *before* writing. This rules out silent fixture substitution at equal total size. The served evidence module declares schema v3; Vite transforms source modules, so this does not claim a byte-identical JS distribution build. The harness inspects HTTP request methods during execution, but cannot establish all possible privacy side effects outside its own browser context.
