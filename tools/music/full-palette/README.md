# Full twelve-mountain Gentle-score palettes — Pope and One More Run

Date 2026-11-15. Owner Marvin explicitly requested complete musical
treatment of BOTH songs, analogous to the 25-second SheetSage2 -12
with V3 Gentle sample he liked. Research-only, not game-integrated.

## Completed full-length private auditions

Pope (3:35, 642 SheetSage2 notes, 12 mountain voices):
http://100.115.120.66:8181/tools/music/audition-full-pope/

One More Run (2:54.6, 333 SheetSage2 notes, 12 mountain voices):
http://100.115.120.66:8181/tools/music/audition-full-one-more-run/

Every song provides all twelve distinct V2/V3 mountain instrumental
sound designs, complete 48kHz Ogg Opus audio (128kbps) for each
instrument, optional full 5-stem backing, the actual isolated original
vocal recording, optional biome room effects and on-clock switching.

The twelve mountain names, all present for both songs:
bitstream-bluffs, debumont, garbage-dump-glacier, pyramid-peak,
underwater-mountain, crystal-cavern, space-mountain,
candy-cane-canyon, sky-jellyfish-mountain, steampunk-slopes,
micro-mountain and vertigo-vents.

The original V2 articulated sonic designs including eight sampled
FluidR3 GM SoundFont instrument programs and custom timbre/FX polish
were reused. The synthetic tone base of each newly generated
voice uses the same SheetSage score-corrected, octave-registered
pitch contours and musical rests, not the old inaccurate V1
fundamental. Both use bounded V3-style relative within-note
expression, max +/-32 cents, weight 0.72, with sheet-supplied
pitch centers/onset events (-12 semitone instrumental register).

CRITICAL PRESERVATION: Pope Vertigo Vents organ in the 12-voice
gallery is the exact earlier full Gentle organ recording: byte-
identical Ogg Opus file, verified SHA256. This is the full
version of the short organ experiment the owner liked, NOT a
re-synthesized or retuned approximation.

One More Run's 333-note score was generated by the existing
locally installed official SheetSage2 + MERT checkpoint on
CT214 from the exact original lead vocals.wav supplied with
the user's 11 stems. The notes start after the instrumental
intro (approx t=11.83s); they are not artificially repeated
over the introduction. The source vocals WAV SHA256:
f67ac4d04cfdd6e8e3c8975d982575a1cac22dea4c824ec8440721ea73c9e8b2

The locally prepared V2 F0/envelope derived from this vocal
supplies within-note movements but NEVER overwrites SheetSage
note identity/octave. The new output is a first listening test:
Marvin has not yet heard/approved the whole song or the twelve
individual instruments, including its new organ.

## Test details

Each song has 14 encoded tracks: 12 full instruments, a separate
original isolated vocal, and full five-stem accompaniment.
All 14 assets per song pass ffprobe duration check within 100ms
of source runtime. Every instrument Ogg file SHA256 matches its
CT211 source copy. PCM masters use exact original frame count
Pope 10,318,847 frames; One More Run 8,380,800 frames, mono 48k.
Level normalization generally about -24dBFS RMS across instruments,
with maximum peaks below 0dBFS. These are LEVEL checks only,
not subjective sound-quality guarantees.

Derived backing for Pope required silence padding only at its
tail (source Demucs stem lengths differ ~0.7 seconds); no
time stretch or time relocation was applied. Both backing files
use drums+bass+guitar+piano+other, not original vocals.
One More Run's supplied 11 stems are known not to perfectly
reconstruct its master; for neutral playback original master
should be used. Grouped 6 stem versions remain available.

Both full galleries passed independent Chromium navigation,
playback of first instrument, mid-song switches among multiple
mountains, original vocal selection, backing/reverb controls,
and all 14 HTTP media links without JS/HTTP errors.
168 focused Jest tests, ten suites, and production Vite build pass.
