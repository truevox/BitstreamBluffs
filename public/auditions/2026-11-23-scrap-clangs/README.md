# Garbage Dump Glacier — sparse irregular real-pitch junk-metal clang audition

**Separate experimental draft, no merge.** Implemented in [Bitstream Bluffs PR #259](https://github.com/truevox/BitstreamBluffs/pull/259), commit `41a02e0`, tracking [issue #258](https://github.com/truevox/BitstreamBluffs/issues/258); based on the Crystal 150%/air-bloom revision PR #257, and ultimately prior biome drafts. Deployed as a **standalone** companion to our older owner-liked Garbage audition; its existing **SPLORP 160% and Sticky Seal Peel A/80%** remain unchanged in game code and preview.

Original source recordings are the same five 20-second synchronized MP3s referenced **unchanged** from the neighboring `/auditions/2026-11-22-scrapheap/stems/` directory. Original stereo masters and separate MIDI-based biome lead are never modified. Our audition **shares the exact `ScrapPitchCadence` pure policy with the game**: seeded irregular timing (average about 1–2sec at normal rate), actual grounded movement only, and actual live bass spectral candidate via the same conservative 4096 FFT test used in Crystal. NO confident current bass pitch means NO clang. The *fundamental* is in-pitch, but noisy and deliberately inharmonic higher metal modes keep Garbage different from Crystal. Separate clang volume 0–200%, occurrence rate 50–200%, automatic on/off, manual **Test next verified-pitch clang** (up to four seconds waiting in preview only), live spectral evidence text, and Play from bass phrase (3sec) let owner hear a real note without waiting through silence. This manual browser wait is not a new game timer.

Short excerpts do not certify full-game true-peak, real mobile hardware, perceptual acceptability or merged status.
