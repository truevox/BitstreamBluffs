# Micro Mountain — miniature-box original-stem audio + actual giant background bees

**Experimental, draft, awaiting owner listening.** Static built browser listening room sourced from game implementation [Bitstream Bluffs draft PR #255](https://github.com/truevox/BitstreamBluffs/pull/255) commit `9d557d0`, issue [#254](https://github.com/truevox/BitstreamBluffs/issues/254). Stacked after Hydrostatic #252, Scrapheap #221 and Snowpack #194. Included in audition draft #201, not merged production.

The preview uses the real original five instrumental MP3 previews, **referenced from existing neighboring Scrapheap `/auditions/2026-11-22-scrapheap/stems/`**; no media masters or source files were altered or duplicated. The separate biome MIDI vocal leads remain in the existing game pipeline. The Web Audio `microbox` DSP on all five ORIGINAL instruments sounds tightly reflective/band-limited on the ground, opens during flight and uses a short deterministic physical box rattle on landing. The spatial wing buzz uses precisely the same pure `beesAt(camera, sceneTime, seed)` positions the game renderer uses (no invented bee spawns). Preview camera and rider screen-position sliders are SIMULATED views for audition, not claims to be live-game tracking.

Evidence (Chromium five-stem, 48kHz, three seconds): full dry mix RMS 0.02566, grounded mini-box RMS 0.01451, open-air 0.02183, ground/flight delta 0.02133, landed box-shake delta RMS 0.00603. Existing visual bee panner left-of-rider dominant right-channel RMS 0.00118 vs left 0.00014, reversed when the rider moves to the opposite side. All sampled peaks below 1, with no nonfinite values. 166 related tests/18 suites and Vite build passed. Browser smoke passes local compiled player. These numbers do NOT prove subjective human audibility or certify true peaks/mobile/whole-song performance. Await owner ears before any production merge.
